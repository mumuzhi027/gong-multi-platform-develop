# 拱拱 uni-app 3

这是根据仓库中的 Kotlin Compose Multiplatform 客户端复现的独立 uni-app 3（Vue 3）工程。原有 `composeApp`、`iosApp` 与 `back` 目录不受影响。

## 开发与构建

```powershell
npm install
npm run dev:h5
npm run build:h5
```

当前维护目标是与原生 App 一致的 iOS PWA。小程序端已停止维护。

## iPhone / PWA（Vue 3）

H5 继续使用本工程的 Vue 3 页面、原有图标和业务接口。后端不需要为 PWA 重写。

```powershell
cd uniapp3
npm run build:h5
npm run test:pwa
npm run test:courses
npm run test:assets
npm run preview:pwa
```

电脑预览地址为 `http://localhost:4173`。构建结果在 `dist/build/h5`，应将整个目录部署到 **HTTPS 域名的根目录**。iPhone 不能用电脑的 localhost 地址访问；局域网 HTTP 仅用于页面调试，不支持正式 PWA 安装和 Service Worker。

宝塔站点 `gonggong.mumuzhi.cloud` 的上传、HTTPS、代理与安装步骤见 [专用部署说明](deploy/宝塔部署-gonggong.mumuzhi.cloud.md)，对应 Nginx 配置片段为 `deploy/gonggong.mumuzhi.cloud.locations.conf`。其他服务器可参考 [通用部署说明](deploy/部署使用说明.md)。

在 iPhone Safari 中打开正式 HTTPS 地址，选择“分享 → 添加到主屏幕”，如果出现“作为 Web App 打开”，保持开启。随后从桌面上的拱拱图标进入，会在独立窗口中打开，不显示 Safari 地址栏和底部工具栏。直接在 Safari 标签页里打开时，网站无法强制隐藏这些浏览器控件。

实现内容：

- 主屏幕图标、Web App Manifest、iOS 独立启动配置。
- 刘海和底部安全区，以及 Safari 动态视口高度适配。
- 按原生首页的屏幕高度分配课程、活动、考试区域，调整登录页和底部导航尺寸。
- 控件按 App 的逻辑尺寸显示，字号和按钮不再随着窗口宽度整体放大；表单按可用宽度伸展。短屏和键盘弹出时压缩登录页留白，并保留页面滚动能力。宽屏网页将应用区域居中，最大宽度 480px，底部导航和弹层保持在同一区域。
- 通知插图、密码可见图标、应用 Logo 和导航等使用从 `composeApp` 原始 VectorDrawable 转换的 SVG，保留原始路径、彩色插图、透明度、圆角描边和渐变。构建前自动同步资源，位图直接复制 App 原文件；通知插图的旧 PNG 回退也提升到 900px 宽，避免 96px 图片放大后模糊。`test:assets` 检查资源与原生来源是否同步。
- 首页和活动页共用海报组件，居中裁切并按原生尺寸设置标题、边距、遮罩与轮播间隔。图片成功加载后才切换白色文字和遮罩；失败时保留可读标题和缩略图占位。活动详情图按原比例铺满宽度，点击预览原图，加载失败不保留大块空白。
- 全部页面代码及本地图标预缓存，首次联网安装完成后支持断网重开及页面切换；课表、成绩等数据复用现有本地缓存。
- 自主添加/编辑/删除课程、按周删除原始课程和恢复本周；本地修改在刷新远端课表后保留，自定义课程优先覆盖同周重叠课程。
- 按构建内容生成缓存版本；新版本下载完毕后提示更新，确认才切换和重启。更新失败保留旧版本。登录与个人数据接口不进入 Service Worker 缓存。

### 接入已有后端

H5 默认调用同域 `/api`，如 `/api/login` 转发至现有后端 `/login`。复制 `.env.example` 为 `.env.local` 可设置开发代理；生产服务器参考 `deploy/nginx.conf.example` 配置 HTTPS 和 `/api/` 反向代理。这个方案支持继续使用现有 HTTP 后端，而浏览器只访问 HTTPS 同域接口。前端必须与后端反向代理一起部署，单纯上传静态文件不会自动提供 API 代理。

如果后端已有可访问的 HTTPS 域名，也可设置 `VITE_H5_API_BASE_URL=https://你的接口域名`，再构建；后端需要允许该网站的 CORS 来源。活动海报的已有 HTTP 后端地址会转为同域代理地址，其他外部海报需使用 HTTPS。

`VITE_H5_WEB_BASE_URL` 指向原生 App 的条款网站，默认 `/web/` 通过服务器代理。现有条款页的内置文本仍是此前 uni-app 工程的简版，正式发布必须核对和替换为 App 使用的完整文本；目前不能视为内容完全一致。

### 验证范围与待验收项

iOS 主屏幕模式使用普通状态栏，避免让正文绘制到半透明系统状态栏下。所有底部布局共享 `--safe-area-bottom`；仅在 iOS standalone 模式将异常安全区上限限制为 34px，处理 WebKit #301172 中把未显示的 Safari 工具栏计入安全区的情况。正常 0/21/34px 安全区保持原值，Android 和普通浏览器标签页保持系统原始安全区。导航总高度和页面预留空间使用同一变量，防止内容被遮住。状态栏变更需要更新后彻底关闭再打开；系统自身的模糊效果仍须真机验收。

仅在 iOS 桌面模式中，主页面导航相对于页面容器定位，绕开 viewport-fixed 元素在某些 WebKit 版本中的偏移；活动内容在独立容器内滚动。优先使用 vh；当全宽、未缩放的桌面视口缺少的高度恰好等于顶部安全区时，恢复到屏幕高度（实际反馈：812/874/62px）。旋转、分屏、不匹配的差值不触发恢复，视觉视口因键盘缩短时保留稳定布局。顶部加入真实、不透明、无交互的完整安全区背景，在受影响的 Safari 27 桌面模式额外避让 16px，尝试避开系统模糊边缘，不宣称能关闭系统自身模糊效果。普通浏览器和 Android 保留原定位。

浏览器检查通过 DevTools 的安全区模拟验证四个主页面的正常竖屏、异常工具栏高度、横屏、无 Home Indicator 和实机反馈的视口缺少 62px 情况，共 20 组布局。检查导航贴底、按钮避开手势区、标题不越出顶部、滚动区不被导航覆盖，并确认 Android/普通浏览器不受限制。增加短于页面的 fixed 包含块回归场景、长活动列表滚动和通过真实菜单导航复制显示反馈的检查。`npm run test:ios-viewport` 另检查高度恢复的启用条件、键盘、缩放、分屏、横屏和正常全屏不重复补高。截图使用模拟环境，不包含 iOS 系统绘制层。

“设置 → 界面显示反馈”提供用户主动复制的显示信息。它记录最近可见主页面的导航几何和视口、安全区、User-Agent、界面修订号及通过 MessageChannel 查询的实际激活 worker 版本。`20261009-ios3` 新增 vh/dvh/lvh 实测值与高度恢复状态，并分别显示原始视口和实际页面高度。不会读取个人存储、页面文字、账号和密码，也不会自动上传。系统版本须用户在 iOS 设置中确认，不能仅凭 User-Agent 推断。

`test:pwa` 检查缓存边界、离线资源完整性、图标尺寸、更新切换和更新失败恢复。`scripts/check-pwa-browser.mjs` 在安装了 Edge 的 Windows 上用独立临时浏览器配置验证 iPhone 尺寸布局、Service Worker、断网重启、六个页面的离线跳转，以及自定义课程添加/持久化/删除。还会解码全部 SVG，检查通知插图的实际像素颜色和 3 倍屏截图，用隔离的横图、竖图、坏图测试海报、详情图比例与原图预览。先启动 `preview:pwa` 再运行该脚本，截图写入仓库的 `tmp/pwa-check`。测试活动只写入临时浏览器数据，不进入正式页面或真实账号。它是 Chromium 自动化测试，不代替 iPhone Safari 真机验收。

`node scripts/check-login-browser.mjs` 验证真实输入组件到请求体的表单编码、特殊字符、快速修改后立即提交、回车及自动填充场景。全部接口通过浏览器拦截返回模拟响应，不向后端尝试测试账号。H5 登录和重新验证在提交时读取当前输入框值，避免输入组件约 100ms 的模型同步延迟提交旧密码；密码不做 trim 或改写。`deploy/诊断登录提交.js` 可在实际站点控制台安装一次性的比较检查，只输出表单与输入框是否一致以及状态码，不输出凭证；用于区分输入同步问题与其他线上登录故障。

当前还不能认定与原生 App “完全一致”：尚未进行 iPhone 主屏幕模式下的逐页视觉对照、真实账号接口联调和深色模式完整对照；原生桌面小组件、安装包更新、后台定时通知也不等同于网页能力。通知页目前只保存偏好，已明确显示后台通知尚未接入。要实现 Web Push，需要后端的订阅保存、发送和提醒调度；仅有现有教务查询接口不足以发送后台通知。

## 上线前配置

1. 配置 HTTPS 站点及同域接口、海报和条款代理。
2. 在 iPhone 主屏幕模式验收安全区、键盘、登录和全部页面。
3. 核对用户协议、隐私政策与权限说明的完整内容。
4. 如启用后台推送，接入后端订阅、发送与提醒调度。

使用 HBuilderX 时请直接打开本目录（包含 `package.json` 的 `uniapp3` 目录），不要只打开 `src`。工程已声明 `vueVersion: 3`，HBuilderX 会使用项目内的 Vite 编译器。

## 页面

- 登录与离线模式
- 首页、今日课程、考试安排、侧边栏
- 完整周课表与课程详情
- 今天/明天空教室及节次筛选
- 学业总览、排名与分学期成绩表
- 通知设置、认证服务、关于与条款页面

接口封装集中在 `src/api`，服务地址集中在 `src/config/env.js`，状态及本地缓存集中在 `src/stores`。
